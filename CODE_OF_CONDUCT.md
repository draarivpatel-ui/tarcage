# Code of Conduct

## Standards

Participants are expected to be respectful, accurate, and constructive. Security research must stay defensive and must not include instructions or artifacts intended to harm third parties.

Unacceptable behavior includes harassment, personal attacks, discriminatory language, publication of private information, credential requests, malicious exploit distribution, and bad-faith security claims.

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or restrict participation when behavior violates these standards. Suspected vulnerabilities belong in the private reporting channel described in `SECURITY.md`, not in public discussions.

## Scope

This code applies to project issues, pull requests, security reports, examples, documentation, and official project communication channels.
